Built on Fossify Messages 1.9.1.

**Blocked keywords become blocking rules.** A blocked keyword used to block every message containing it anywhere, even a message you wanted. A rule now holds conditions in cards joined by AND, each with a list of words joined by OR. "Contains the word *winner* or *prize*, AND contains *claim* or *click*" blocks the prize scam and leaves "we were the winners tonight" alone.

**Four kinds of condition.** Contains matches anywhere, inside longer words too. Contains the word matches whole words only, so *car* does not match *scar*. Doesn't contain excludes words, though a rule needs at least one condition that looks for something. Matches pattern takes a regular expression; one that will not compile or would match every message is flagged before it can be saved.

**Match case and unknown senders.** Matching ignores case unless the rule says to match it exactly, and a rule can apply only to numbers not in your contacts, MMS included.

**Try a rule before saving it.** A box at the bottom of the editor runs the rule on any message you paste in, ticking each condition as it goes.

**Your keywords carry over.** Keywords you already blocked become one-condition rules. Export writes the rules as JSON, and import takes that or a keyword list exported from Fossify.

Everything in 2.2.2 is unchanged otherwise.
